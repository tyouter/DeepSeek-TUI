- **分支**: feat/REQ-20260511-001-session-picker-fix
- **PR**: [#1510](https://github.com/Hmbown/DeepSeek-TUI/pull/1510)
- **验收标准**:
  - [ ] 会话列表的 Title 列显示用户首条 prompt 的摘要（而非 `<turn_meta>` 等系统标签）
  - [ ] 预览面板的首条 USER 消息展示纯用户 prompt（排除系统前缀和 turn_meta 块）
  - [ ] 历史对话中，USER 和 ASSISTANT 消息均完整显示（不再出现大量空 USER/空 ASSISTANT）
- **备注**: 用户反馈的三个具体症状：
  1. Title 全部显示为 `<turn_meta>`
  2. 首条 USER 消息混入了系统前缀内容（turn_meta 块），导致无法识别真正的首句 prompt
  3. 前几次对话中 USER/ASSISTANT 消息显示不全（大量空条目）
